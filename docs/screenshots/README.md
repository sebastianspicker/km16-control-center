# README screenshots

These JPEGs were captured from the running macOS app on September 14, 2026, using
factory profiles and a separate temporary profile library. Live actions were
disabled; OBS and Codex were not connected. The images are unedited app-window
captures. `workspace.jpg` was re-captured on September 27, 2026, the same way,
after the legend-card redesign of the pad drawing.

To update the tour, build the app and launch it with `KM16_PROFILES_PATH` set to an
absolute path in a new temporary directory. Capture the Desktop workspace, the
Developer entry in Preset Library, the Start Workday assignment in Personal
Automations, and the top of Connections. Preview is sufficient; no live action is
needed. Check every image for personal paths, credentials, and private content
before replacing the files linked by the root README.
