# Photo Editing: Affinity Pixel Studio

This preset targets Pixel Studio in the unified Affinity app (`com.canva.affinity`), rather than the separate Affinity Photo 2 app. Open a photo and select Pixel Studio before use. Retouching, Vector, Layout, and Develop can assign the same keys differently.

The first row covers Undo, Redo, Save, and Export. The remaining keys handle crop, move and selection tools, selection cleanup, layers, and mask colours. The upper-left dial changes brush width and selects Paint Brush. The upper-right changes brush hardness and selects the erase group. The main dial controls canvas zoom and fits the image.

## Check the studio bindings once

Open Affinity > Settings > Shortcuts, select Pixel, and keep your existing shortcut set. Check or assign these actions, especially after migrating from Photo 2 or when using a non-U.S. keyboard:

| Action | KM16 shortcut |
| --- | --- |
| Crop / Move | C / V |
| Selection brush group / Freehand selection | W / L |
| Paint Brush / Erase group | B / E |
| Decrease / Increase brush width | [ / ] |
| Decrease / Increase hardness | Shift-[ / Shift-] |
| Reset foreground/background to black and white | D |
| Swap foreground/background colours | Shift-X |

Hardness changes work only with compatible pixel brushes. Tool-group shortcuts may cycle tools according to Affinity's modifier-to-cycle setting. Finish text or numeric entry before using unmodified tool keys. KM16 Control Center does not change the active studio, tool, brush, or canvas focus.

The document and layer shortcuts follow Affinity's published Mac conventions: save Command-S, export Command-Option-Shift-S, duplicate Command-J, new pixel layer Command-Shift-N, copy merged Command-Shift-C, merged visible layer Command-Option-Shift-E, deselect Command-D, and invert selection Command-Shift-I. Zoom uses Command-minus, Command-plus, and Command-0.

The linked Photo 2 reference documents the baseline shortcuts. Affinity 3 studios and migrated shortcut sets can differ, so confirm the mappings in the table above. The preset does not change Affinity's settings.
