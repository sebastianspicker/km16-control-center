# Research & Writing: CotEditor, Safari, and Notes

This preset uses CotEditor (`com.coteditor.CotEditor`) for Markdown, Safari (`com.apple.Safari`) for reading, and Notes (`com.apple.Notes`) for capture. Install CotEditor from its official distribution; Safari and Notes are included with macOS.

1. In CotEditor, save drafts with an `.md` or `.markdown` extension so its Markdown syntax definition is selected automatically. You can also choose Syntax > Markdown manually.
2. Open CotEditor > Settings > Key Bindings, find Outline, and assign `Control-Command-O`. The Outline dial press needs this custom binding.
3. Grant KM16 Control Center access in System Settings > Privacy & Security > Accessibility.
4. Review the four Markdown snippets before use. The link contains `example.com` as a replacement marker, and the code block uses `text` as a neutral language marker.

Safari Reader works only on pages Safari recognizes as articles. Linked-note navigation works only when Notes has a note-link history. Keyboard layouts and custom app bindings can change the effective shortcuts.
