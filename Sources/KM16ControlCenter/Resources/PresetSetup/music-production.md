# Music Production: Logic Pro

This preset targets Logic Pro (`com.apple.logic10`) and follows Apple's factory U.S. key-command set. It needs no custom key commands with that set and does not act as a MIDI control surface.

1. In Logic Pro, choose Logic Pro > Key Commands > Presets > U.S. to match the factory assignments exactly.
2. Grant KM16 Control Center access in System Settings > Privacy & Security > Accessibility.
3. Open a disposable project, select a track, and test Record Enable, track creation, Duplicate Track, Delete Track, and Bounce.
4. Confirm the selected track is routed to the intended input and that monitoring, count-in, metronome, and cycle settings are appropriate before pressing Record.

The controls are arranged as follows:

| Controls | Assignment |
| --- | --- |
| Key row 1 | Record, Cycle Mode, Metronome, Record enable |
| Key row 2 | Undo, Redo, Save, Bounce |
| Key row 3 | New audio track, New instrument track, Duplicate track, Delete track |
| Key row 4 | Mixer, Automation, Piano Roll, Library |
| Upper-left encoder | Previous track / Next track / Mute track |
| Upper-right encoder | Rewind / Forward / Play or stop |
| Main encoder | Horizontal zoom out / Horizontal zoom in / Zoom selection or all |

Track creation, deletion, automation, and arrangement editing depend on the Main Window and current selection. Rewind, Forward, zoom, and editor toggles follow Logic Pro's normal keyboard focus. Record starts Logic Pro's standard recording action on record-enabled tracks. The preset does not choose an input, arm every track, change audio settings, or bypass prompts.
