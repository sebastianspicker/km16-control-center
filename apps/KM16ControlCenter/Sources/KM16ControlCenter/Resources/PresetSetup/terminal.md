# Terminal: Apple Terminal

This preset targets Apple's built-in Terminal app (`com.apple.Terminal`). It needs no custom bindings when the standard macOS shortcuts are unchanged.

The eight command controls insert editable text at the current shell prompt. They do not add a newline or press Return. Review or change every command before running it. Process snapshot and listening-port commands can produce substantial output on a busy Mac.

Grant KM16 Control Center access in System Settings > Privacy & Security > Accessibility. If a shortcut differs under your keyboard layout, compare it with Terminal's menu bar and update the preset.

Reference: [Keyboard shortcuts in Terminal on Mac](https://support.apple.com/guide/terminal/trmlshtcts/mac).
