# Window Management: macOS

The 16 keys act on the foreground app and its focused standard window. Grant KM16 Control Center access in System Settings > Privacy & Security > Accessibility so it can read, move, resize, minimize, and focus windows.

Placement uses the visible area of the window's current display. KM16 Control Center handles quarter placement and movement between displays because macOS does not provide default shortcuts for every matching Window-menu command. Restore Size becomes available after the app records an earlier frame for that window. Dialogs, sheets, games, and fixed-size windows may reject Accessibility resizing.

The dial shortcuts follow the current macOS and app settings:

- Confirm Move left a space, Move right a space, Mission Control, and Application windows under System Settings > Keyboard > Keyboard Shortcuts > Mission Control.
- `Command-Backtick` and `Shift-Command-Backtick` follow the active app's Window menu.
- `Command-Plus` and `Command-Minus` affect document or content zoom only in apps that expose those standard shortcuts.
- `Control-Command-F` follows the active app's full-screen command.
