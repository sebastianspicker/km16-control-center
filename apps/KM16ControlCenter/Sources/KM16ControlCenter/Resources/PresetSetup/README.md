# Preset setup guides

KM16 Control Center includes setup guides for profiles that need another app, custom binding, local service, or user-owned automation. Read the relevant guide before enabling live actions. Exporting the guides does not install apps or change their settings.

- [Recording & Streaming](recording-streaming.md)
- [Research & Writing](research-writing.md)
- [Terminal](terminal.md)
- [Video Editing](video-editing.md)
- [Window Management](window-management.md)

The `keybindings/git-review.code-keybindings.json` file is an additive Visual Studio Code keybindings fragment. Copy its entries into the outer array of your existing `keybindings.json`; do not replace that file with the fragment.
