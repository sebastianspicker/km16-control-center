# Video Editing: Final Cut Pro

This preset targets Final Cut Pro (`com.apple.FinalCut`) and uses Apple's default command set.

1. Install Final Cut Pro through an Apple-supported distribution, then open or create a library.
2. Choose Final Cut Pro > Command Sets > Default to match Apple's defaults exactly.
3. To keep a custom command set, open the Command Editor with `Option-Command-K`, compare the preset bindings, and update any that differ.
4. Grant KM16 Control Center access in System Settings > Privacy & Security > Accessibility.
5. Test Blade, Blade All, Overwrite, and Delete on a duplicate project. Final Cut Pro's Undo command is available on the preset.

Share uses the destination currently configured as Final Cut Pro's default. Import, playback, and editing controls follow Final Cut Pro's current selection and keyboard focus.
